# Alien Defender — เกมยานอวกาศยิงเอเลียน

โปรเจกต์ Python + Pygame สำหรับเรียนรู้ Game Loop, การจัดการสถานะ, การตรวจจับการชน และการบันทึก JSON
กราฟิกวาดด้วยโค้ด และเสียงสังเคราะห์สร้างขึ้นสำหรับโปรเจกต์นี้ ไม่ต้องดาวน์โหลดภาพหรือเสียงเพิ่ม

## สมาชิกกลุ่ม

- นายรชานนท์ สารจันทร์ CE6841
- นายศาสวัติ บุตรศรีรักษ์ CE6841
- นายศิวากร พิมพะนิตย์ CE6721

## ติดตั้งและเปิดเกมบน Windows

ต้องมี Python 3.10 ขึ้นไป และอินเทอร์เน็ตเฉพาะตอนติดตั้งไลบรารีครั้งแรก
แตก ZIP ก่อนเปิดใช้งาน แล้วเปิด Terminal ในโฟลเดอร์ alien_defender

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

หากติดตั้ง pygame-ce ใน Python หลักแล้ว สามารถใช้ `python main.py` หรือดับเบิลคลิก `run_game.bat`
อย่าติดตั้ง pygame และ pygame-ce ร่วมกันใน environment เดียว เพราะใช้ชื่อ import เดียวกัน
บน Linux/macOS ใช้ `python3 -m venv .venv` และ `.venv/bin/python` แทนคำสั่ง Python ของ Windows

## เมนูและการเล่น

- New Start: เลือกยาน แล้วเริ่มเกมใหม่ (ใช้ชื่อนี้แทน New Stat)
- Save Game: บันทึกเกมปัจจุบัน มีในหน้าหลักและหน้า Pause
- Load Game: โหลดเซฟล่าสุด
- Settings: ปรับเสียงเพลง เสียงเอฟเฟกต์ และระดับ Easy / Normal / Hard โดยคลิกเพื่อวนค่า
- Continue: กลับเข้าเกมที่เล่นค้างอยู่ในหน่วยความจำ
- Quit: ออกจากเกม

| ปุ่ม | การทำงาน |
| --- | --- |
| W A S D / ลูกศร | เคลื่อนที่ |
| Space ค้าง | ยิง |
| Esc | หยุดชั่วคราว / เล่นต่อ / ย้อนกลับ |
| F5 | บันทึกขณะเล่นหรือหยุดชั่วคราว |
| F9 | โหลดเซฟล่าสุด |

ยาน Falcon สมดุล (HP 100), Titan ทนทาน (HP 160), Swift เร็วและยิงถี่ (HP 75)
กำจัดเอเลียนทั้งหมดเพื่อผ่านด่าน ได้ 100 คะแนนต่อตัว และฟื้น HP 15 เมื่อผ่านด่าน
ด่านสูงขึ้น เอเลียนเคลื่อนเร็ว ยิงถี่ และมี HP เพิ่ม ทุกครั้งที่โดนโจมตีจะมีช่วงป้องกันความเสียหาย 0.8 วินาที

## ระบบเซฟและเสียง

เซฟอยู่ที่ `%LOCALAPPDATA%\AlienDefender\save.json` และการตั้งค่าอยู่ใน `settings.json` โฟลเดอร์เดียวกัน
ถ้าไม่มี LOCALAPPDATA จะใช้โฟลเดอร์ home แทน
เซฟเก็บยาน ตำแหน่ง HP คะแนน และหมายเลขด่าน เมื่อโหลด **จะเริ่มศัตรูในด่านนั้นใหม่** ไม่เก็บกระสุนหรือศัตรูรายตัว
มีเซฟหนึ่งช่อง การกด Save จะเขียนทับเซฟเดิม การเริ่มเกมใหม่ไม่ลบเซฟจนกว่าจะกดบันทึก
เกมไม่บันทึกอัตโนมัติตอนออก และไม่อนุญาตเซฟเมื่อแพ้
ระดับความยากใช้ค่าจาก Settings ปัจจุบัน ไม่ได้ผูกกับเซฟ
ไฟล์เสียหรือไม่มีเซฟจะแสดงข้อความในเกม ไม่ปิดโปรแกรม
หากเปิดอุปกรณ์เสียงไม่ได้ เกมยังเล่นแบบไม่มีเสียงได้

เพลงและเสียงอยู่ใน `assets/` สร้างซ้ำได้ด้วย `python generate_audio.py`

## โครงสร้างและแนวคิดการทำงาน

```text
alien_defender/
  main.py              หน้าจอ เมนู การควบคุม และระบบต่อสู้
  storage.py           ตรวจสอบเซฟและเขียน JSON ผ่านไฟล์ชั่วคราว
  generate_audio.py    สร้างเพลงและเอฟเฟกต์ WAV
  assets/              music.wav, shoot.wav, explosion.wav, hit.wav
  tests/test_game.py   ทดสอบเซฟและสถานะเกมแบบไม่เปิดหน้าต่าง
  requirements.txt
  run_game.bat
  README.md
```

1. `Game.__init__` เริ่มหน้าต่าง อ่านการตั้งค่า และโหลดเสียง
2. `run` รับ input อัปเดตตำแหน่งตามเวลาจริง และวาดภาพ 60 FPS
3. `state` เลือกหน้าจอ menu, select, play, pause, settings หรือ over
4. `update_play` เคลื่อนยานและกระสุน ตรวจชน เพิ่มคะแนน และเปลี่ยนด่าน
5. `save` ส่งข้อมูลให้ `atomic_write` เขียนไฟล์ชั่วคราวแล้วแทนที่เซฟเดิม เพื่อลดความเสี่ยงไฟล์เขียนไม่ครบ
6. `load_game` ตรวจเวอร์ชัน ชื่อยาน ชนิดข้อมูล และช่วงค่าก่อนนำเซฟกลับมาใช้

ภาพใช้ `pygame.draw` จึงเปลี่ยนสีและรูปทรงได้โดยไม่ต้องมีโปรแกรมวาดภาพ
รายการกระสุนและศัตรูใช้สำเนารายการขณะตรวจชน เพื่อให้ลบสมาชิกระหว่างวนลูปได้อย่างปลอดภัย
ฟังก์ชันปุ่มเลือกยานใช้ `lambda n=name` เพื่อจับชื่อยานของการ์ดแต่ละใบ ไม่ให้ทุกปุ่มเลือกยานใบสุดท้าย
